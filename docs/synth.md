# 合成器场景：设计与实现计划

圆键 3 的场景：一台以 Teenage Engineering EP-133 K.O. II 为蓝本的采样器 / 鼓机。M18 是控制面，声音引擎跑在 Mac 上。
本文是设计依据和分期计划；硬件事实见 [architecture.md](architecture.md)，视觉与动画规则见 [design.md](design.md)。
起草：2026-10-29。

## 1. 目标与边界

- **以 EP-133 的功能为蓝本，不复刻它的操作方式**。它靠 12 个压感 pad、两个旋钮、一根推子和大量双键组合；
  M18 只有 15 个屏幕键，而且一次只能识别一个键。交互按 M18 重新设计，功能尽量保留。
- **不用 TE 的出厂采样**。默认音色自己合成或录制，或用明确可再分发（CC0 等）的素材；用户自己的 `.ppak` 可以导入（第四期）。
- 名字不用 "K.O." 等 TE 的商标。

### EP-133 的功能（OS 2.5，作为蓝本）

| 模块 | 内容 |
|---|---|
| 结构 | 9 个 Project；每个 4 组（A–D）× 12 pad；每组 99 个 Pattern；99 个 Scene（记录 4 组各用哪个 Pattern）；Song 最多 99 个位置 |
| 采样库 | 999 槽 / 128 MB；原生 46,875 Hz；单声道最长 40 s；同时发声 16 单声道 / 12 立体声 |
| 声音编辑 | oneshot / key / legato，声像，裁剪，attack / release，变速（BPM / 按小节 / 倒放），MIDI 通道与根音，互斥组 |
| 音序器 | 96 PPQN，一步 24 tick；Pattern 1–99 小节；实时 / 步进录音，叠录 / 覆盖；力度、时值（1 tick – 1 小节）；量化 / 自由；整体平移；Note repeat；Swing；复制粘贴撤销 |
| Keys | 12 pad 成为半音键盘，切八度与调式（含 Blues、和声小调、旋律小调）；琶音器 |
| 推子 | 每组分配 12 个参数之一并可录自动化：LVL PTC TIM LPF HPF FX ATK REL PAN TUNE VEL MOD |
| 主效果 | 同时只有一个：Delay、Reverb、Distortion、Chorus、Filter、Compressor（各两个参数），每组送量；总线压缩；sidechain |
| Punch-in FX | 12 个，按住 FX + pad，压力控制强度，可叠加：beat repeat、tape stop、LPF tremolo、LPF、HPF、FX send、mute slicer、降八度、bit 降采样、音高随机、pad 随机、stutter |
| 采样 | 麦克风 / line in / USB；免手持触发；等长自动切片；重采样；速度检测 |
| 同步 | MIDI 进出（音符、CC、时钟、program change）、模拟同步口、USB 音频 |

来源：TE 官方指南（teenage.engineering/guides/ep-133）；参数编号与效果类型参考社区逆向文档
[kmorrill/ep-series-sysex](https://github.com/kmorrill/ep-series-sysex) 的 `midi-reference.md`；Punch-in FX 列表参考
[josephharrington/ep133-cheatsheet](https://github.com/josephharrington/ep133-cheatsheet)。

## 2. 硬件约束

| 约束 | 后果 |
|---|---|
| **一次只识别一个键**（2026-10-29 实测，任何方向都一样） | 没有组合键；不能多个 pad 同时打；所有"修饰"都改成锁定状态 |
| 没有旋钮、推子、力度、压感 | 调值靠按键面板；力度靠力度层、重音、按住时长 |
| 事件约以 10 ms 为单位到达 | 演奏延迟预算里要算上这 10 ms |
| 屏幕键 64×64，60 Hz；同时动的键数 × 帧率 ≤ 450 张/秒 | 每个键都能显示状态；大面积动画要错开或降帧 |
| 24 颗灯（环 22 + 左右短条 2） | 播放头、模式色、录音状态 |
| 圆键 1/2/3 固定切场景 | 合成器场景内的所有操作都在 15 个屏幕键上完成 |

"只按住一个键"是完全可靠的：按下、按住多久、何时松开都准确。所有设计都建立在这一点上。

## 3. 交互模型

### 3.1 一个原则：修饰键改成锁定状态

EP-133 的"按住 A + 按 B"一律改成"**点 A 进入一个状态（锁定，屏幕和灯带显示出来），再按 B**"。同一时刻永远只按着一个键。
按住 B 本身仍然可以是临时动作（按住生效、松手结束），因为这时只有 B 一个键按着。

### 3.2 手势

| 键类 | 手势 | 说明 |
|---|---|---|
| pad（演奏） | **按下即发声，松开即结束** | 不做长按、双击，不能等松手判断；按下反馈照常 |
| 功能键 | **按下即展开 / 切换** | 不等松手、不做长按第二功能，响应最快 |
| 菜单项 | 按下即执行 | 选择类执行后收起菜单；开关类留在菜单里、键变白 |
| 危险操作 | 长按 1 秒（`KeyHold`） | 清空 Pattern、删除采样、覆盖录音等 |

不用双击：双击要等第二下，第一下就得延迟执行。

### 3.3 层级：最多两层

- **第 0 层：演奏面**。12 个 pad + 3 个功能键，打鼓、弹奏、播放 / 停止都在这一层。
- **第 1 层：功能菜单**。功能键展开，菜单项覆盖 12 个 pad 的位置。
- **第 2 层：调值面板**。菜单里选中一个参数后出现；终点，不再往下。

返回：展开它的那个键保持白色（`on`），表示"你在这里"，按它退回上一层。在任何层级，**音序器都照常播放**。

### 3.4 展开菜单的动画

- 菜单从按下的键出发，按距离一圈一圈扩散到位，**落点固定**：同一个菜单永远一样的布局，不随出发的键变化。
- **输入不等动画**：键一显示新内容就可以按，动画只是视觉效果。
- 帧率按 design.md 的预算：一圈一圈错开时，同一时刻在动的键少，整体保持 60 帧；超出时由控制器统一降到 30 帧。
- 曲线用 `Motion.ease`，大面积运动帧用 `KeyRenderer.motionQuality`，落定帧用全画质（与翻页同一套）。

### 3.5 调值面板（代替旋钮和推子）

```
 0%   25%  50%  75%  100%     ← 一行 5 个键是一根分段推子，点哪格跳到哪
  −   数值   +   默认  返回     ← − / + 微调，按住连续变化并加速（KeyRepeater）
 （第三行：同一页上的相邻参数，点一下切换过去）
```

- 分段推子负责粗调，− / + 负责细调；数值键显示当前值，变化时用 `ValueTransitions` 缓动。
- "默认"把参数恢复到初始值。
- 录音状态下点分段推子的格子，会在当前位置录下一段自动化（代替推推子）。

### 3.6 力度（代替压感）

- **力度层**：12 个 pad 都变成当前声音，从左上到右下力度递增（MPC 的 16 Levels 思路）。
- **重音**：一个锁定开关，打开后打出的音按高力度录入。
- 每个 pad 有默认力度；录好的音符在步进编辑里逐步改。
- Punch-in FX 的强弱改用**按住时长**：按得越久效果越深（tape stop、降采样、滤波天然适合）；每个效果也可以预设强度。

### 3.7 补上"同时"

硬件不能同时打两个 pad，用三种办法补：

1. **叠层 pad**：一个 pad 同时触发几个声音（底鼓 + 踩镲）。
2. **步进叠录**：先后录到同一步上，回放就是同时的。
3. **和弦 pad**：Keys 模式下一个 pad 弹出当前调式的整个和弦。

### 3.8 起点布局（草案，要在实物上调）

```
 pad  pad  pad  pad │ 组 A     ← 显示当前组；按下展开模式菜单
 pad  pad  pad  pad │ FX       ← 按下进入效果页（锁定）
 pad  pad  pad  pad │ ▶︎        ← 按下播放 / 停止；录音待命时红色
```

- **组键菜单**（覆盖 12 个 pad）：第一行 A B C D；第二行 打击 / Keys / 力度层 / 步进；第三行 声音编辑 / 录音 / 速度 / 更多。
- **FX 效果页**：12 个 pad 变成 12 个 Punch-in FX。按住 = 临时生效，快点一下 = 锁定常开（再点关闭）；
  先锁定几个、再按住一个，就是叠加。效果页里的"更多"进主效果、送量、总线压缩、sidechain。
- **▶︎**：只做播放 / 停止，响应要最直接。录音在组键菜单里待命，待命时 ▶︎ 变红，按 ▶︎ 开始录。
- pad 键面：采样名（英文短名）或编号；正在发声时提亮；所属组的互斥、叠层用标记表示。
- 灯带：播放时环上走播放头（按 22 颗环灯的实际坐标排一小节）；录音时红；效果页时用效果页的颜色。灯效遵守 design.md 的灯光规则。

圆键 3 在合成器场景里重复按下的含义（现有规则是翻页）待定：建议合成器只有一页，重复按 = 回到演奏面。改之前先改 design.md。

## 4. 实现分期

每期结束时都要能在 M18 上实际用起来，并由用户在实物上确认。

### 第零期：地基

- **音频引擎**：进程内 AVAudioEngine + `AVAudioSourceNode` 自己渲染，48 kHz。实时线程里不加锁、不分配内存、不调 Objective-C；
  主线程到引擎的命令走无锁环形队列。
- **延迟实测**：从按键事件到声音出来，目标 ≤ 20 ms（事件粒度约 10 ms + 一个缓冲区）。
  做一个 `dock-probe` 命令，用麦克风录下按键声和发出的声音来量；缓冲区大小按实测定。
- **合成器模块**：一个占满 15 键的 `DockModule`，内部是层级状态机（演奏面 / 菜单 / 调值面板）和键面描述；不碰其他场景。
- **展开菜单动画**：与动画引擎一起做，放在 DockCore（其他场景以后也能用）。
- **数据格式**：工程存为 JSON + WAV，放在 `~/Library/Application Support/StreamDock/Synth/`；采样在内存里是 Float32。
- **默认音色**：一套自己合成的鼓组（底鼓、军鼓、踩镲、拍手等），保证开箱能出声。

### 第一期：能做出节奏

- 4 组 × 12 pad 的采样播放：oneshot / key / legato，音高、音量、声像、attack / release、裁剪、互斥组；同时发声 32 个。
- 音序器：96 PPQN，在渲染回调里按采样点精确调度；Pattern 1–99 小节；步进录音与实时录音（预备拍、叠录、覆盖）；
  量化；Swing；速度与 tap tempo；节拍器。
- 一个主效果 + 每组送量；总线压缩。
- 撤销 / 重做；工程自动保存。
- 测试：用离线渲染检验音序器时间（误差 ≤ 1 个采样点）、voice 分配、互斥组。

### 第二期：能演奏

- Keys 模式（八度、调式、和弦 pad）；力度层；重音。
- Note repeat（锁定后按住 pad 连打，跟随 Swing）。
- 12 个参数的自动化（分段推子录入；起点值、终点值和曲线生成渐变）。
- Scene、Song；复制、粘贴。
- 12 个 Punch-in FX；sidechain。
- MIDI 输出与时钟（进 / 出），可以带外部合成器。

### 第三期：能采样

- 从麦克风、音频接口或系统声音录采样（复用 `MusicAudioTap` 的系统声音采集）；免手持触发（超过阈值开始）。
- 切片、等长自动切片；变速（跟 BPM / 按小节）、倒放；重采样（把整体输出录回成采样）；速度检测（复用 RhythmKit）。
- 琶音器（依次点 pad 放进琶音组，锁定后自动播放）。

### 第四期（可选）

- Mac 端编辑窗口：拖拽导入 WAV、看波形裁剪、批量命名。
- 导入 / 导出 EP-133 的 `.ppak`（格式按社区文档）。
- 叠层 pad 的编辑、更多主效果。
